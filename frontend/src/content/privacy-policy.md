## 1. 운영자와 이용 기관의 역할

이용 기관은 아동·보호자 정보를 입력하고 기록을 관리하며 그 처리 목적·적법한 근거·보유기간을 정합니다. 운영자는 기관의 지시에 따라 해당 자료를 처리하고, 회원 계정·서비스 보안 정보는 서비스 운영을 위해 처리합니다. 기관 내부에서도 역할과 담당 아동에 따라 접근 범위를 제한합니다.

아동·보호자의 권리 행사 요청은 해당 기관에 할 수 있습니다. 운영자에게 접수하면 요청자의 권한과 기관을 확인하여 처리를 돕습니다. 만 14세 미만 아동의 개인정보와 건강·장애 등 민감정보는 기관이 법정대리인의 동의, 별도 동의 또는 그 밖의 적법한 근거를 확인한 후 입력해야 합니다. 회원가입만으로 아동·보호자의 동의가 대신되지는 않습니다.

## 2. 처리하는 개인정보 항목·목적·수집 방법

| 구분 | 처리 항목 | 이용 목적 |
|---|---|---|
| 회원·가입 신청 | 이메일, 인증용 비밀번호, 이름, 소속 기관명, 역할·가입 승인 상태, 방침 동의 버전·시각 | 가입·로그인, 기관 연결, 승인·권한 관리, 문의 처리 |
| 아동 기본 정보 | 이름, 가명코드, 생년월일, 선택 입력한 성별·메모·담당 치료사·보호자 연락처 | 아동별 기록·일정 관리 |
| 업무·상담 기록 | 입력한 회기·상담 내용, 발화·행동·어휘 관찰, 치료계획·목표, 일정·출결, 수업 결제 구분·기관 정산 자료, 생성 문서 | 기록 초안 작성·검토, 일정·출결·서류 등 기관 업무 지원 |

| 녹음 | 이용자가 시작하거나 선택한 음성 파일, 파일명·길이·처리 상태, 녹취록·요약 초안·검토 기록 | 받아쓰기·요약, 중단된 업로드 재시도, 초안 검토 |
| AI 대화·첨부 | 질문·답변, 선택한 아동의 필요한 기록, 이용자가 첨부한 사진·문서의 내용과 파일명·형식, AI 초안·승인 이력 | 질문 응답, 요청한 초안 생성·검토 |
| 보안·이용 기록 | IP 주소, 접속 시각·요청 경로·응답 상태, 브라우저·앱 정보, 사용자 식별자·기관·수행 작업 등 감사기록 | 인증·접근 통제, 부정 이용 방지, 장애·보안 사고 확인 |

정보는 회원과 기관 사용자의 직접 입력·파일 업로드·기능 실행으로 수집되며, 접속·처리 과정에서 일부 기록이 자동 생성됩니다. 비밀번호는 Firebase Authentication이 관리하며 운영자가 원문을 열람하지 않습니다.

녹음·AI 대화·첨부는 선택 기능입니다. 사용하지 않아도 이용 가능한 직접 기록·일정 기능은 계속 이용할 수 있습니다. 연락처·메모 등 선택 항목을 제공하지 않으면 그 정보를 사용하는 기능만 제한될 수 있습니다. 광고 ID, 휴대폰 주소록, SMS, 정확한 위치를 수집하는 기능은 사용하지 않습니다.

현재 서비스는 발달검사 결과·문항 응답을 새로 입력받는 기능을 제공하지 않습니다. 이전에 저장한 관련 자료가 있는 경우 기관 기록과 같은 접근 통제·삭제 기준을 적용합니다.

## 3. 보유기간과 삭제 시점

| 정보 | 보유·삭제 기준 |
|---|---|
| 회원·가입 정보 | 회원 탈퇴 처리 시 서비스 회원·가입 신청 정보를 삭제하고 인증 계정 삭제를 요청합니다. Firebase 인증 정보는 사업자 정책에 따라 삭제 요청 후 운영·백업 시스템에서 최대 180일 이내 제거됩니다. |
| 아동·보호자·기관 기록, 대화·초안·녹취록·생성 문서 | 이용 기관이 정보주체에게 안내한 보유기간과 적법한 삭제 지시에 따릅니다. 기관에 보유기간과 근거를 확인할 수 있습니다. 서비스가 모든 기관에 동일한 보유 연수를 임의 적용하지 않으며, 보관 처리만으로 자동 영구 삭제되지는 않습니다. |
| 녹음 원본·분할 파일 | 서울 리전의 비공개 저장소에 처리 중 임시 보관합니다. 현재 원본 추가 보관 설정은 0일이며 정상 받아쓰기 병합 후 원본·분할 파일 삭제를 요청합니다. 실패·중단 등으로 남은 파일에는 분할 파일 생성 후 3일, 원본 생성 후 30일의 저장소 삭제 규칙이 적용됩니다. 규칙 적용 후 실제 삭제까지 처리 지연이 있을 수 있습니다. |
| 삭제한 저장소 파일 | 녹음·생성 문서 저장소는 삭제 후 7일 동안 서비스 일반 화면에서 접근할 수 없는 복구용 사본을 보유합니다. 이후 저장소 정책에 따라 영구 삭제됩니다. |
| 데이터베이스 이전 버전 | 현재 데이터베이스에는 변경 전 버전을 1시간 보관하는 설정이 적용됩니다. 일반 서비스 화면에서는 삭제한 자료를 열람할 수 없습니다. |
| 서버 접속·장애 로그 | 현재 서버 로그 저장소의 보유기간은 30일입니다. 클라우드 인프라 관리 활동·시스템 이벤트 감사로그는 사업자 기본 정책에 따라 400일 보유됩니다. |
| 서비스 내부 감사기록·계정 차단 식별자 | 접근 통제, 기관 업무 이력·보안 사고 확인 및 적용되는 보존 의무를 위해 보유합니다. 이 기록에는 현재 공통 자동 삭제 기한이 설정되어 있지 않습니다. 삭제 요청 시 보존 필요성·적용 법령·기관 지시를 확인하여 삭제 또는 식별정보 제거 여부와 사유를 안내합니다. 아동 영구 삭제 시 기존 감사기록에서 해당 아동의 직접 연결값을 제거합니다. |
| 휴대폰·브라우저에 남은 자료 | 로그인 상태·화면 설정은 로그아웃 또는 기기·브라우저의 저장 데이터 삭제 시까지 남을 수 있습니다. 업로드하지 못한 녹음은 재시도를 위해 앱 내부 저장소에 남으며, 업로드가 완료되면 앱이 해당 사본을 삭제합니다. 기기 밖으로 직접 내보낸 파일은 이용자가 별도로 관리·삭제해야 합니다. |

다른 법령에 따른 보존이나 진행 중인 분쟁·보안 사고 대응 때문에 삭제가 제한되는 경우에는 해당 정보·근거·기간을 요청자에게 안내하고 필요한 범위에서만 보관합니다. 기관 기록의 보유기간이 끝나거나 적법한 삭제 요청이 확인되면 기관과 운영자가 필요한 파기 절차를 진행합니다.

## 4. 파기 절차와 방법

삭제 권한·대상·기관의 보존 의무를 확인한 후 데이터베이스의 대상 자료와 연결된 생성 파일을 삭제합니다. 보관 처리와 영구 삭제는 구분하며, 전자 자료는 활성 저장소에서 삭제하고 복구용 사본은 3항의 기간 후 제거합니다. 법령상 보존 대상은 목적 외 이용·접근을 제한합니다.

## 5. 제3자 제공과 기관 내 이용

운영자는 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 같은 기관의 권한 있는 사용자는 업무 범위에서 기관 기록을 볼 수 있습니다. 이용자가 다운로드·공유한 자료의 전달 대상은 이용자가 정합니다. 외부 사업자의 처리 업무와 국외 이전은 6항·7항과 같습니다. 법령에 따른 요구가 있는 경우에는 필요한 범위에서 처리합니다.
