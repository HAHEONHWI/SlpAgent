# SLP Agent 사이트맵 · 기능 리스트 (리디자인용)

기준: `frontend/src` 현재 구현 (2026-10-16). 화면 이름은 실제 메뉴 라벨 그대로.

## 0. 사용자 역할과 보이는 화면

| 역할 | 진입 화면 | 메뉴 차이 |
|---|---|---|
| 비로그인 | 로그인 / 가입 신청 | 개인정보처리방침(`/privacy`)만 공개 |
| 가입 승인 대기 | 가입 대기 화면 | 임상 화면 접근 불가 |
| 서비스 관리자 (site_admin) | 전체 관리자 대시보드 (별도 앱) | 임상 화면 전체 없음 |
| 기관 관리자 (admin) | 대시보드 | 전 메뉴 + 기관 설정 + 정산 |
| 치료사 (therapist) | 대시보드 | 기관 설정 없음, 정산은 회계 담당 지정 시만 |
| 보조 (읽기 전용) | 대시보드 | 치료활동 생성 없음, 작성·승인 버튼 비활성 |
| 회계 담당 (can_settle) | — | 정산 메뉴 노출 |

## 1. 사이트맵

```
[공개]
├─ 로그인                      /
│   ├─ 로그인 · 비밀번호 찾기
│   └─ 가입 신청 (기관명, 본인 이름, 개인정보 동의)
├─ 가입 승인 대기               (status ≠ active)
└─ 개인정보처리방침             /privacy

[기관 사용자 — 공통 레이아웃]
├─ 상단바: 메뉴(모바일) · 로고 · 아동 선택(전역) · 월령 · 공지 알림(배지) · 기관명 · 내 계정 · 로그아웃
├─ 좌측 메뉴 (그룹 접기/펼치기, 상태 기억)
│
├─ 대시보드                     /
├─ 매일
│   ├─ 일정 관리                /schedule
│   ├─ 출결 관리                /attendance
│   ├─ 수업 기록                /sessions        ※ 아동 선택 필요
│   ├─ 수업 기록 조회           /class-records
│   └─ 아동 관리                /children
├─ 아동 평가·치료               ※ 모두 아동 선택 필요
│   ├─ 발달검사 관리            /assessments
│   ├─ 통합 발달 분석           /analysis
│   ├─ 행동분석                 /behavior
│   ├─ 어휘 발달 관리           /vocabulary
│   ├─ 치료계획                 /plans
│   └─ 발달 진행도 분석         /progress
├─ AI
│   ├─ AI 대화                  /ai              (전체 화면 레이아웃)
│   ├─ 치료활동 생성            /activities      ※ 아동 선택 필요, 작성 권한
│   └─ AI 지식자료실            /knowledge
├─ 행정
│   ├─ 바우처·문서 생성         /voucher         ※ 아동 선택 필요
│   ├─ 정산                     /settlement      ※ 관리자·회계 담당
│   ├─ 공지사항                 /notices
│   └─ 기관 설정                /settings        ※ 관리자
└─ (메뉴 밖) 내 계정            /account

[서비스 관리자 — 별도 화면]
└─ 전체 관리자 대시보드
    ├─ 가입 신청 · 기관 · 계정 · 사이트 공지 · 전체 휴무일 · 받아쓰기(STT) · API 문서
```

## 2. 화면별 기능 리스트

### 공통 / 전역
- **아동 선택(ChildPicker)**: 상단바에서 전역 선택, "아동 선택 안 함(일반 모드)" 가능. 아동 필수 화면은 미선택 시 안내(RequireChild).
- **공지 알림**: 안 읽은 공지 수 배지, 공지사항 진입 시 해제.
- **AI 초안 원칙**: AI 결과는 "미승인 초안" → 치료사 승인/반려 후에만 기록 반영 (DraftView 공통 패턴).
- 인쇄 대응(시간표·문서), 모바일 메뉴는 3열 아이콘 그리드.

### 로그인 · 가입
- 로그인(이메일·비밀번호), 비밀번호 찾기(메일 발송 안내)
- 가입 신청: 아이디, 비밀번호·확인, 기관명, 치료사 이름, 개인정보 동의
- 가입 대기: 승인 여부 확인 / 다시 확인 / 로그아웃
- 개발용 로그인(역할 선택) — 개발 환경 전용

### 대시보드 `/`
- 카드 3개: 담당 아동 수, 승인 대기 AI 초안, 검사 자료 준비 상태(문항 미적재·규준 없음 표시)

### 일정 관리 `/schedule`
- **주간 시간표(Timetable)**: 기준 주 선택, 칸 클릭으로 아동 넣기/빼기, 칸 닫기, 메모·시작일·종료일, 강조 표시, 인쇄
- **시간·교사 설정**: 수업(분)·상담/쉬는(분), 오전/오후 시작·타임 수, 점심시간, 운영 요일, 담당 교사 순서(↑↓)·약칭
- **날짜별 일정**: 수업 추가, 일정 목록(수정·취소) — 시간표에서 자동 생성
- **기관 휴무일**: 추가/삭제

### 출결 관리 `/attendance`
- 기본 출석 처리, 예외만 기록
- **일별 출결**: 수업별 결석 / 사유결석 / 지각 / 해제, 시간 수정, 보강(옮기기·옮기기 취소), 수업 추가
- **월별 출결 현황**
- **장기결강**: 기간 등록 (해당 기간 수업은 시간 점유 안 함)
- 바우처 서류에 자동 반영

### 수업 기록 `/sessions`
- **수업 기록 쓰기**: 날짜, 시작·종료(선택), 담당 치료사, 수업 내용, 보호자 안내, 다음 수업·후속 조치, 주제·참여자 태그
  - 활동 행 추가: 활동 내용, 정반응/전체 시행, 촉진, 아동 실제 발화, 관찰 행동
- **녹음 파일로 기록 만들기**: 종류(치료 회기/보호자 상담), 업로드 → 압축·분할·받아쓰기 진행 상태, 다시 시도·취소
  - 검토: 녹취록 보기·수정, 고친 녹취록으로 다시 요약, 요약(수업 요약·보호자 질문·안내·가정 연계 활동·후속 조치), 승인/반려
- **녹음 기록** 목록

### 수업 기록 조회 `/class-records`
- 필터: 아동(전역 선택 연동), 치료사, 월, "기록 없는 수업만"
- 달별 수업 + 출결 + 수업 기록·활동 기록·녹음 기록 통합 조회

### 아동 관리 `/children`
- 아동 등록: 가명코드, 이름, 생년월일, 성별, 담당 치료사, 장애등록 여부, 바우처 등급(없음=유료)
- 아동 목록: 선택(전역 아동 지정), 수정, 삭제(휴지통 — 이후 일정 취소)
- **엑셀로 한꺼번에 등록**: 파일 업로드, 미리보기, 기존 아동 덮어쓰기 옵션
- **휴지통**: 복원, 영구 삭제

### 발달검사 관리 `/assessments`
- 검사 결과 입력: 검사 선택, 문항 은행 있는 검사는 **문항 체크리스트**, 없으면 범용 항목 입력, 저장
- 검사 이력 (점수·백분위는 산출하지 않음)

### 통합 발달 분석 `/analysis`
- 분석 종류: 통합 발달 분석(검사 기록 필요) / 행동 패턴 분석
- AI 초안 생성 → 근거(Claim) 목록 → 승인/반려, 승인된 기록 이력

### 행동분석 `/behavior`
- ABC 관찰 기록: 선행사건·행동·결과, 환경, 빈도·지속시간·강도(기관 척도), 저장
- 관찰 기록 목록

### 어휘 발달 관리 `/vocabulary`
- 어휘 기록: 수용/표현, 습득 상태(미관찰·출현·촉진 후·독립), 관찰일
- 차트: 수용·표현 비교, 어휘 습득 변화(누적)
- 단어별 이력(모달)
- 가정연계 어휘 목록(초안)

### 치료계획 `/plans`
- 새 계획 버전(초안): 장기·단기 목표 행 추가, 측정 방법·수행 기준·근거, 초안 저장
- 버전 목록: 승인·활성화 (이전 활성 버전은 대체 상태)

### 발달 진행도 분석 `/progress`
- 활동별 정반응률 추이(%) 차트

### AI 대화 `/ai`
- 대화 모드: 언어치료 지식 / 임상 대화 (대화별 고정)
- 대화 기록 사이드패널(이전 대화, 새 대화)
- 파일 첨부, 개인정보 확인 체크, 메시지 입력·전송
- 참고한 기관 자료 표시
- **검토 대기** 패널: 초안 수정 저장, 승인/반려

### 치료활동 생성 `/activities`
- 활동 조건: 목표 영역, 현재 수행 수준, 선호 활동, 준비물, 치료시간(분), 촉진 수준
- AI 초안 → 승인/반려, 승인된 기록

### AI 지식자료실 `/knowledge`
- 자료 목록, 자료 검색(키워드)

### 바우처·문서 생성 `/voucher`
- 월별 집계(코드 계산: 시간·횟수·금액)
- 문서 출력: 문서 종류 × 형식(DOCX/PDF, 바우처는 HWPX)
  - 바우처 서류, 치료 경과보고서, 평가 결과 요약서, 보호자 상담기록, 서비스 제공기록지, 서비스 일정표, 보호자 안내문(승인됨)
- **바우처 기록지(HWPX)**: 시작·끝 월(최대 12개월), 바우처 단가, 본인부담금, 기관 전화, 회기 행 편집(날짜·시간·담당·수업 내용), 기타사항 행, 기록에서 다시 불러오기
- 생성된 문서: 다운로드, 검토 완료·승인

### 정산 `/settlement` (관리자·회계 담당)
- 월별 정산: 아동별 바우처·본인부담금·유료 수업 금액 (결석·옮긴 수업 제외)
- 발달재활서비스 기준 안내
- 유료 단가 미설정 경고 → 기관 설정 링크

### 공지사항 `/notices`
- 사이트 공지 + 기관 공지 통합, 고정 공지 상단
- 공지 작성·수정(관리자)

### 기관 설정 `/settings` (관리자)
- 기관명
- 행동 강도 척도(최소·최대)
- 단가: 바우처 / 바우처 야간 / 일반(유료) / 일반(유료) 야간, 바우처 월 한도(분)
- 치료사 목록(추천 이름 불러오기, 추가·저장)
- 회계 담당 지정
- 감사로그(최근 100건)

### 내 계정 `/account`
- 비밀번호 변경, 회원 탈퇴(마지막 관리자는 불가 안내)

### 전체 관리자 대시보드 (서비스 관리자)
- **가입 신청**: 상태 필터, 승인(승인 방식·역할 지정) / 거절(사유)
- **기관**: 목록·집계, 이름 변경, 검사 사용권한 편집, 다른 기관에 병합(옮겨질 데이터 미리보기, ID 확인)
- **계정**: 검색, 소속 기관·역할 변경, 사용 상태, 삭제
- **사이트 공지** 작성, **전체 휴무일** 관리
- **받아쓰기(STT)** 현황·설정
- **API 문서**

## 3. 리디자인 시 참고 포인트
- 아동 의존 화면이 11개 → 전역 아동 선택의 위치·상태 표시가 핵심.
- "AI 초안 → 승인/반려" 패턴이 6곳(AI 대화, 통합 분석, 치료활동, 녹음 기록, 치료계획, 문서)에서 반복 → 공통 컴포넌트화 대상.
- 일정 관리 ↔ 출결 ↔ 바우처·정산은 같은 데이터 흐름(시간표 → 날짜별 일정 → 출결 → 서류·정산).
- 수업 기록 / 수업 기록 조회 / 발달 진행도는 같은 기록의 쓰기·보기·추이 — 통합 여지.
- 역할별 숨김/비활성 규칙(§0) 유지 필요.
