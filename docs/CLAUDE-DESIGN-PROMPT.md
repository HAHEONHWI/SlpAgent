# Claude Design 프롬프트

아래 전체를 복사해 붙여넣으세요.

---

언어재활사(언어치료사)가 치료실에서 쓰는 AI 업무보조 웹서비스 **SLP Agent**의 UI를 디자인해 주세요. 이미 동작하는 서비스(React + Tailwind)가 있고, 화면 구조와 기능은 유지한 채 완성도 높은 B2B SaaS 디자인으로 다시 그리는 것이 목표입니다.

## 사용자와 사용 환경
- 주 사용자: 언어재활사(치료사), 기관 관리자. 30~50대, IT 숙련도는 보통.
- 사용 환경: 데스크톱 중심(1280~1920px), 치료실 태블릿(1024px 세로/가로) 대응. 회기 사이 짧은 시간에 빠르게 입력해야 함.
- 다루는 정보: 아동의 발달검사 결과, 치료 기록, 행동 관찰 등 민감한 개인정보.
- 언어: 한국어 UI. 본문 글꼴은 Pretendard 계열.

## 디자인 방향
- 차분하고 신뢰감 있는 의료·교육 업무 도구. 화려함보다 가독성과 입력 속도.
- 표와 차트 중심의 정보 밀도 높은 화면이지만 여백과 위계로 정돈.
- 주 색상은 인디고 계열(현재 #4F46E5). 상태 색: 초안/검수 필요=앰버, 승인/완료=그린, 오류/거절=레드, 정보=슬레이트.
- 라이트 모드 기본, 다크 모드 토큰도 정의.
- 접근성: 본문 대비 4.5:1 이상, 키보드 포커스 표시, 클릭 영역 최소 36px(태블릿 44px).

## 반드시 디자인에 드러나야 하는 원칙
1. **AI 출력은 항상 "미승인 초안"**: AI가 만든 모든 결과(분석, 기록문, 활동, 상담자료)는 승인 전까지 앰버색 "미승인 초안" 표시. 치료사가 "검토 완료·승인"을 눌러야 기록이 됨. 승인된 것과 초안이 한눈에 구분되어야 함.
2. **근거 표시**: AI의 각 문장 아래에 근거 칩(예: "근거: SELSI · 문항 5 · 2026-09-01", "근거: ABC 관찰 · 2026-09-04"). 근거가 없는 주장은 존재하지 않음.
3. **진단하지 않음**: 행동기능은 "잠정 가설 (확정 아님)"으로 라벨링. 진단처럼 보이는 표현·아이콘 금지.
4. **점수를 지어내지 않음**: 규준표가 없는 검사는 표준점수·백분위 칸에 "규준 없음" 배지. 빈칸을 숫자처럼 보이게 하지 말 것.
5. **"검수 필요"**: 자동 추출된 검사 문항에는 작은 앰버 "검수 필요" 배지.
6. **개인정보 최소 노출**: 아동은 가명코드(예: A-01)를 우선 표시하고 실명은 보조. 사이트 관리자 화면에는 아동 정보 없이 집계 숫자만.

## 전체 레이아웃
- 왼쪽 사이드바(접기 가능): 로고 + 16개 메뉴(아이콘+라벨).
- 상단 바: **아동 선택기**(가장 중요한 전역 컨트롤. 검색 가능한 콤보박스, 가명코드·이름·나이 표시, "아동 선택 안 함(일반 모드)" 옵션), 기관명, 사용자 이메일, 로그아웃.
- 아동이 선택되지 않은 상태에서 아동 전용 화면에 오면 안내 상태(empty state).

## 그려야 할 화면
1. **로그인 / 회원가입**: 탭 전환. 가입 필드 = 아이디(이메일), 비밀번호, 비밀번호 확인, 기관명, 치료사(본인) 이름. "가입 후 관리자 승인이 필요합니다" 안내.
2. **승인 대기 화면**: 가입 후 승인 전. 상태 배지(승인 대기/승인됨/거절됨 + 사유), "승인 여부 확인" 버튼.
3. **대시보드**: 담당 아동 수, 승인 대기 AI 초안 수, 이번 주 일정, 검사 자료 준비 상태(검사별 규준/문항 적재 여부 배지).
4. **AI 대화**: ChatGPT처럼 메시지를 주고받는 화면. 대화 이력, 파일·이미지 첨부, Markdown 답변, 기관 자료 출처·페이지 표시. 아동 모드 배지를 보여주고, 승인 대기 초안은 별도 검토 영역에 둔다.
5. **아동 관리**: 등록 폼 + 아동 목록 표.
6. **발달검사 관리**: 검사 선택 → 문항 체크리스트(수용언어/표현언어 섹션 → 영역 → 월령 그룹, 문항마다 응답 버튼 그룹 + "검수 필요" 배지, "응답 12/90" 진행 표시) + 검사 이력 표(펼치면 문항 응답).
7. **통합 발달 분석 / 행동 패턴 분석**: 탭. "AI 초안 생성" → 섹션 카드들(평가 개요, 강점, 지원 필요, 불일치, 치료목표 후보 등), 각 문장 아래 근거 칩. 하단 "승인된 기록" 이력.
8. **행동분석(ABC 관찰)**: 선행사건-행동-후속사건 입력 폼 + 관찰 기록 표.
9. **어휘 발달 관리**: 어휘 입력 폼, 수용/표현별 누적 막대 차트(출현 중/촉진 시 가능/독립 사용), 가정연계 어휘 칩 목록, 단어별 상태 이력.
10. **치료계획**: 장기·단기목표 편집 폼, 버전 카드(초안/활성/이전 버전 배지), "승인·활성화".
11. **치료활동 생성**: 조건 입력 → 활동 초안(목적, 준비물, 진행 순서, 모델링 예시, 반응 유도, 난이도 조절, 측정, 보호자 연계).
12. **회기별 치료기록**: 날짜·시간, 활동별 정반응/시행·촉진 수준, 아동 발화 입력 + 회기 카드 목록.
13. **발달 진행도 분석**: 활동별 정반응률(%) 꺾은선 차트.
14. **보호자 상담**: 상담 기록 폼 + 이력 타임라인.
15. **바우처·문서 생성**: 월별 집계(회기 수, 총 제공시간, 바우처 사용/추가구매, 금액) + 문서 출력(종류·형식 선택, 생성된 문서 목록, 초안/승인됨 배지, 다운로드). "승인번호·서명은 수기 입력" 안내.
16. **AI 지식자료실**: 자료 목록(텍스트 추출/OCR 필요 상태 배지) + 검색 결과(문서명·페이지·발췌).
17. **일정 관리**: 월 선택 + 일정 표(시간 충돌 시 오류 표시).
18. **기관 설정**: 기관명, 행동 강도 척도, 회기 단가, 바우처 한도 + 관리자 전용 감사로그 표.
19. **사이트 관리자 대시보드**(별도 레이아웃, 사이드바 없음): KPI 6개, 가입 신청 표(승인/거절 사유 입력), 기관 표(사용자·아동 수, 최근 활동, 사용 허가 검사 칩 + 편집).

## 컴포넌트와 상태
- 버튼(주/보조/위험/고스트), 입력, 셀렉트, 텍스트영역, 세그먼트 버튼 그룹(문항 응답용), 배지, 근거 칩, 카드, 표, 빈 상태, 로딩 스켈레톤, 토스트, 확인 대화상자.
- 모든 화면에 로딩 / 비어 있음 / 오류 / 권한 없음(403: "이 기관은 해당 검사의 사용 허가가 없습니다") 상태를 포함.

## 산출물
- 디자인 토큰(색, 타이포, 간격, 반경, 그림자) 정의.
- 위 화면들의 데스크톱 시안, 그리고 1·4·6·12번은 태블릿 시안 추가.
- 컴포넌트 시트.
- 실제 화면에는 가짜 데이터만 사용(예: 아동 "A-01 · 테스트아동", 기관 "샘플 언어치료센터"). 실존 인물·기관 이름 금지.
