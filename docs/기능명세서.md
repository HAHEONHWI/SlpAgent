# SLP Agent 기능명세서

## 문서 정보

- 서비스: SLP Agent
- 대상: 언어치료 기관의 관리자·치료사·보조 사용자 및 서비스 관리자
- 운영 상태: 배포 완료 (사용자 확인)
- 범위: 현재 저장소의 화면과 API 구현 기준

## 1. 사용자 역할

| 역할 | 권한 |
|---|---|
| 서비스 관리자 | 가입 승인·반려, 기관 현황 조회, 검사 사용권한 관리. 임상기록 열람 불가 |
| 기관 관리자 | 기관 설정, 임상 데이터 조회·작성·승인 |
| 치료사 | 임상 데이터 조회·작성·AI 초안 검토·승인 |
| 보조 사용자 | 허용된 기관 데이터 조회. 임상 데이터 작성·승인 불가 |

## 2. 기능 요구사항

| ID | 기능 | 명세 |
|---|---|---|
| FR-01 | 계정·기관 접근 | 로그인 계정을 기관 역할에 연결한다. 가입 승인 전에는 임상 화면에 접근할 수 없다. |
| FR-02 | 대시보드 | 담당 아동 수, 승인 대기 AI 초안, 검사 문항·규준 준비 상태를 보여준다. |
| FR-03 | 아동 관리 | 가명 코드, 표시 이름, 생년월일, 성별, 보호자 연락처, 메모를 관리한다. 목록·상세 조회와 보관 처리를 제공한다. |
| FR-04 | 발달검사 | 기관 사용권한이 있는 검사 정의·문항을 제공하고, 문항별 응답·관찰·총점을 기록한다. 검사 시 월령을 계산한다. |
| FR-05 | 행동 관찰·분석 | 선행사건·행동·결과(ABC), 환경, 빈도·지속시간·강도 등을 기록하고 행동 분석 초안을 생성한다. 강도는 기관 척도를 따른다. |
| FR-06 | 어휘 발달 | 수용·표현 어휘와 습득 상태(미관찰·출현·촉진 후·독립)를 기록·검색한다. 목표 어휘 중 독립 전 항목으로 가정용 목록을 만든다. |
| FR-07 | 치료 목표·계획 | 장·단기 목표, 측정 방법, 수행 기준, 근거를 기록한다. 승인된 계획을 활성화하고 이전 활성 버전은 보존하며 대체 상태로 바꾼다. |
| FR-08 | 치료 일정 | 아동·치료사·일시별 일정을 등록·조회·취소한다. 같은 아동 또는 치료사의 겹치는 일정은 거부한다. |
| FR-09 | 회기 기록 | 회기 일시, 치료사, 활동별 정반응·시행 횟수·촉진 수준, 발화, 관찰 행동을 저장한다. 활동별 정반응률과 회기 시간을 계산한다. |
| FR-10 | 진행도 | 완료된 회기의 활동별 정반응률 추이를 그래프로 보여준다. 표준화 검사 점수와 합산하거나 직접 비교하지 않는다. |
| FR-11 | 보호자 상담 | 상담 일시·상담자·참석자·주제·요약·안내·후속조치를 기록·조회한다. 입력한 시작·종료 시간으로 상담 시간을 계산한다. |
| FR-12 | 언어치료 지식 Q&A·임상 대화 | 기본 지식 모드는 기초 개념·검사 원리를 설명하고 기관 자료와 일반 지식을 구분하며 아동 기록·임상 도구를 사용하지 않는다. 임상 모드는 명시적으로 선택하고 대화 중 변경할 수 없다. 파일·이미지 첨부와 Markdown·출처·페이지 표시를 지원한다. 임상 초안 도구는 질문별 허가와 쓰기 역할을 확인하며, 초기 임상 의견은 치료사 검토용 초안으로 제공한다. |
| FR-13 | AI 분석·활동 제안 | 통합 발달 분석, 행동 분석, 치료 활동을 생성한다. 결과는 근거 검증 후 미승인 초안으로 저장한다. |
| FR-14 | AI 제안 검토 | 치료사·기관 관리자가 제안을 수정·승인·반려한다. 승인 전에는 임상 기록에 반영하지 않는다. |
| FR-15 | 지식자료실 | 기관별 임상 문서를 검색하고 문서명·페이지·인용 정보를 제공한다. 검수 또는 OCR이 필요한 자료는 검색 결과에서 제외한다. |
| FR-16 | 비용·바우처 요약 | 월별 회기 시간·횟수·금액을 요약한다. 금액은 기관 단가가 설정된 경우에만 계산한다. |
| FR-17 | 문서 생성 | 서비스 기록지, 일정표, 경과 보고서, 검사 요약, 보호자 상담 문서를 생성·조회·승인하고 만료 시간이 있는 비공개 다운로드 링크를 제공한다. DOCX·PDF를 지원한다. |
| FR-18 | 기관 설정 | 기관명, 행동 강도 척도, 회기 단가, 바우처 시간을 설정한다. |
| FR-19 | 운영·감사 관리 | 서비스 관리자는 가입·기관·검사 권한과 집계 현황을 관리한다. 임상 데이터 변경 및 AI 도구 사용은 감사 기록에 남긴다. |

## 3. 주요 업무 흐름

1. 사용자가 로그인하고 기관 승인을 받는다.
2. 치료사가 아동을 등록하고 검사·행동·어휘·회기·상담 기록을 작성한다.
3. 필요하면 AI 대화·분석·활동 생성으로 초안을 만든다.
4. 치료사 또는 기관 관리자가 근거와 내용을 검토해 승인하거나 수정·반려한다.
5. 승인된 자료로 치료 계획을 관리하고 월별 요약·문서를 생성한다.

## 4. 공통 정책

- 모든 임상 데이터 접근은 기관 범위로 제한한다. 아동 자료는 아동 소유 기관을 확인한다.
- 쓰기 작업과 AI 도구 사용을 감사 로그에 남긴다.
- AI에는 가명 코드와 필요한 최소 임상 정보만 전달한다. 알려진 이름·연락처 및 일반 이메일·전화 패턴은 전송 전에 가린다.
- 업로드 파일과 검색 자료는 낮은 권한의 user 참고 입력으로 분리한다. 지시문·역할·도구 목록을 클라이언트가 바꿀 수 없고, 서버가 질문별 도구 권한을 검증한다. 모델 답변의 HTML·외부 이미지 로딩과 외부 링크 클릭을 비활성화한다. 프롬프트 인젝션의 완전 탐지를 보장하지 않는다.
- AI 출력은 초안이다. 치료사 승인 전 기록·계획을 자동 변경하지 않는다.
- 시간·횟수·금액은 공통 billing 서비스에서 계산한다.

## 5. 현재 제약

- 공식 규준표가 없어 규준 기반 점수·발달연령·백분위는 산출하지 않는다. `norm_unavailable` 상태를 유지한다.
- 현재 문항은행은 검수 전이다. 검사 자료 사용권한을 기관별로 확인한다.
- HWPX 출력은 입력 템플릿의 토큰과 반복 행 처리가 필요해 운영 지원 완료로 간주하지 않는다. 문서 생성은 DOCX·PDF가 기준이다.
- 저장소의 테스트는 AI 호출을 fake client로 검증했다. 실제 운영 AI 연결·배포 환경 동작은 이 문서 작성 시점에 별도 검증하지 않았다.
